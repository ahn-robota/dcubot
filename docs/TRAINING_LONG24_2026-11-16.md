# long23·long24 학습 변경 내용 (2026-11-16, 실습실 PC)

`SIM2REAL_DEBUG_2026-11-13.md` 7절(V자 서기) 질문에 대한 답과, 지금 학습 중인 long24 내용. 그 파일은 노트북에서 수정 중일 수 있어서 따로 적는다. 자세한 기록은 master의 `docs/CHANGES_FROM_ORIGINAL.md` #26, #27과 `docs/AUTO_EXPERIMENTS_2026-10-28.md`.

## 7절 질문에 대한 답

1. **V자 서기는 시뮬에서도 똑같이 재현된다.** 명령 0으로 10초 세워두면 long17, long18, long23 모두 양쪽 hip_yaw가 약 -9.5~-9.9도, 즉 관절 한계(±10도)에 붙어서 발끝이 바깥으로 약 10도 벌어진다. 걸을 때도 마찬가지다(전진 중 hip_yaw -9.8도, 흔들림 0.1도). long22 25.6M은 서 있을 때 -6.3도. 참조 동작(reference)은 hip_yaw를 평균 0도 근처로 쓰므로 정책이 스스로 고른 자세다. 시뮬에서 V자로 서면 발 사이(충돌 형상 기준)가 23 mm에서 6.8 mm로 줄어든다 — 실물의 발끼리 간섭과 맞다.
2. **`stand_still` 가중치**: bringup의 `joystick.py`는 옛날 값(`-0.2`)이다. 학습에 쓰는 master는 이미 `-1.0`(#18). 다만 모든 관절을 같은 가중치로 더하기만 해서 hip_yaw 10도 정도는 압력이 약한 건 맞다.
3. **`self._weights`**: 맞다, upstream에서부터 정의만 있고 쓰이지 않던 코드. long24에서 서 있을 때 자세 벌점(`stand_hip_pose`)에 실제로 쓰도록 했다.
4. **제자리걸음**: 실물 체감이 맞았다. 그리고 long23에서 시뮬 수치로도 해결됐다(아래).

## long24 (2026-11-16 06:48 시작, 실습실 PC 학습 중)

long23 17.0M에서 이어서, 사용자 승인 하에 추가 (master CHANGES #27):

- `hip_yaw_pose = -2.0` (새 항): 양쪽 hip_yaw의 home(0도)에서의 차이 절댓값 합. 서 있을 때와 걸을 때 항상.
- `stand_hip_pose = -5.0` (새 항): 명령 0일 때만, 다리 10관절의 `self._weights * |q - home|` 합 (hip_yaw, hip_roll, ankle 1.0 / hip_pitch, knee 0.01).

- 학습 속도 약 5% 느려짐. 끝나면 배포할 때 xml(발 hull, pair 추가)도 같이 bringup에 올린다.
- 예상 종료: 2026-11-16 낮 12:30~13:00. 끝나면 hip_yaw 각도, 발·다리 간격, 서 있을 때 발 들림, 64대 평가를 재서 이 문서에 추가.
